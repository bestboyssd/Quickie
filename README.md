# Quickie

![quickie logo](https://raw.githubusercontent.com/G00fY2/quickie/gh-pages/media/logo_dark.svg#gh-dark-mode-only)
![quickie logo](https://raw.githubusercontent.com/G00fY2/quickie/gh-pages/media/logo_light.svg#gh-light-mode-only)

Quickie is an Android QR code and barcode scanner app, built with the [Quickie scanner library](https://github.com/G00fY2/quickie).

## Download

Get the APK from [GitHub Releases](https://github.com/bestboyssd/Quickie/releases).

## Features

- Scan QR codes and barcodes
- View saved scans in history
- Open, copy, or share scan results

## Build

Install Android SDK 36, then run:

- Windows: `gradlew.bat :app:assembleDebug`
- macOS/Linux: `./gradlew :app:assembleDebug`

The APK is created at `app/build/outputs/apk/debug/app-debug.apk`.
